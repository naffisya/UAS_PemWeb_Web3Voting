# Blockchain Voting System
Aplikasi web full-stack yang mengintegrasikan blockchain Ethereum (Sepolia Testnet) untuk sistem voting yang aman, transparan, dan terdesentralisasi.

Fitur
Frontend React.js: Interface responsif untuk voting
Backend Node.js/Express: RESTful API untuk data transaksi
Integrasi Blockchain: Koneksi ke Sepolia testnet menggunakan Ethers.js
Smart Contract: Voting contract dengan fitur anti-double voting
Wallet Integration: Koneksi dengan MetaMask
Responsive Design: Layout menggunakan CSS Grid dan Flexbox
Real-time Results: Tampilan hasil voting real-time

Teknologi
Frontend: React.js, Ethers.js, CSS3
Backend: Node.js, Express.js
Blockchain: Ethereum Sepolia Testnet, Solidity
Tools: MetaMask, Remix (untuk deployment)
